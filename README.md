# SMART TRAFFIC React

React/Vite implementation of the two Stitch screens supplied in the project ZIP.

## Pages
- Opening / Welcome Gateway
- Secure Login Portal
- Traffic Officer / Administrator role selector

## Run
```bash
npm install
npm run dev
```

The project uses the Stitch visual design and Tailwind CDN configuration. The local SMART TRAFFIC logo is included at `src/assets/logo.png`.

## Next step
Replace the demo sign-in behavior in `src/pages/Login.jsx` with your Flask/API authentication and route each role to its dashboard.
